# RCMS 수입처리 자동화 시나리오

학교 시스템의 과제별 집행액이 전날보다 늘어난 과제를 매일 찾아, 그 증가분에 해당하는 입금을 수입결의하는 업무를 자동화한다. 모든 자료는 학교 시스템에서 엑셀로 받는다.

## 처리 단계

| 단계 | 작업 | 자료 | 방식 |
|---|---|---|---|
| ① | 과제별 집행액을 전날과 비교해 증가 과제·증가액 찾기 | 학교 시스템 엑셀 | 자동 |
| ② | 증가 과제의 세부 집행내역 다운로드 | 학교 시스템 엑셀(과제별) | 수동 다운로드 → 자동 취합 |
| ③ | 전날 집행 건을 골라 증가액과 대조해 대상 확정 | ②의 결과 | 자동(불일치만 확인) |
| ④-1 | 대상 과제의 입금내역 확인 | 학교 시스템 엑셀(과제별) | 수동 다운로드 → 자동 취합 |
| ④-2 | 적요를 참고해 수입 대상 선별 | ④-1의 결과 | 자동 매칭(애매한 건만 판단) |
| ④-3 | 수입결의 | 학교 시스템 | 미정 |

## 시트 구성

| 시트 | 내용 |
|---|---|
| 집행액_일별 | 날짜별 과제 집행액 누적 |
| 증가과제 | ①의 결과: 과제번호, 증가액, 다운로드 체크 |
| 세부집행 | ② 과제별 엑셀 취합 |
| 입금내역 | ④-1 과제별 엑셀 취합 |
| 매칭결과 | ③·④-2 결과와 검토 칸 |
| 적요규칙 | 수입 대상 적요 패턴(웹앱 「적요관리」 탭) |
| 처리이력 | 중복 방지 거래 키, 처리일, 결의번호 |

## 웹앱 반영
- RCMS·보조금사업 탭 모두 카드 5개 표시: 과제, 미처리 과제, 미처리 건, 미처리액, 자동화 대상
- 카드는 공통 함수로 그리고, 서버 집계 함수가 구분값(RCMS/보조금사업)으로 계산
- 예외: 이미 처리한 거래 제외, 합계 불일치 보류, 휴일 다음날은 '직전 처리일 이후'로 비교

## 남은 확인 사항
- [ ] 샘플 엑셀(집행액 전날·오늘, 세부 집행내역, 입금내역), 개인정보 가림
- [ ] 적요 패턴·입금↔집행 대응 관계는 샘플로 도출
- [ ] ③ 기준 날짜 칸(집행일/결의일/지급일)
- [ ] ④-3 수입결의 입력 항목, 일괄 업로드 가능 여부
- [ ] 웹앱 Apps Script 코드(보조금사업 탭 카드 추가용)
