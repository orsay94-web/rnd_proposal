# Second Brain — Claude 작업 규칙

이 폴더는 Obsidian 볼트이자 Git 저장소입니다. Claude Code는 이 폴더에서 실행해 노트를 읽고 씁니다.

## 폴더 구조 (PARA)
- `00-Inbox/` — 빠른 메모, 미분류 자료. 새 노트는 기본적으로 여기에.
- `10-Projects/` — 마감이 있는 진행 중 과제 (예: 연구과제 제안서).
- `20-Areas/` — 지속적으로 관리하는 영역 (연구 분야, 행정, 교육).
- `30-Resources/` — 참고 자료, 논문 요약, 공고문 정리.
- `40-Archive/` — 끝난 프로젝트.
- `Daily/` — 일일 노트 `YYYY-MM-DD.md`.
- `Templates/` — 노트 템플릿.

## 규칙
- 모든 노트는 Markdown, 파일명은 사람이 읽을 수 있는 제목으로.
- 노트 사이 연결은 `[[위키링크]]`를 사용하고, 새 노트를 만들면 관련 노트에 역링크를 추가.
- 맨 위에 YAML frontmatter: `created`, `tags`, `status`.
- 기존 노트를 삭제하지 말고 `40-Archive/`로 이동.
- `.obsidian/` 설정 파일은 수정하지 않음.
- 작업 후 변경 내용을 요약한 메시지로 커밋.

## 자주 하는 요청
- "Inbox 정리해줘" → `00-Inbox/`의 노트를 분류해 알맞은 폴더로 이동하고 링크 추가.
- "오늘 데일리 노트 만들어줘" → `Templates/Daily.md`로 `Daily/` 에 생성.
- "○○ 관련 노트 찾아 요약해줘" → 볼트 전체 검색 후 요약을 `30-Resources/`에 저장.

## 데이터 컬렉터 히스토리 체크
- 위치: `20-Areas/데이터컬렉터/` (개요), `20-Areas/데이터컬렉터/히스토리/` (날짜별 기록)
- "데이터 컬렉터 기록해줘" → `Templates/DataCollector.md`로 `히스토리/YYYY-MM-DD.md` 생성. 같은 날 파일이 있으면 아래에 추가.
- "데이터 컬렉터 히스토리 체크해줘" → `히스토리/`의 모든 기록을 날짜순으로 읽고 다음을 정리:
  1. 실패/오류가 난 날짜와 원인
  2. 수집 건수의 급증·급감
  3. 기록이 빠진 날짜
  4. 미완료 조치 사항(`- [ ]`)
  결과는 `20-Areas/데이터컬렉터/데이터컬렉터 히스토리 요약.md`에 덮어써 저장하고 화면에도 요약.
- 로그 파일(.log, .csv)을 받으면 원본은 `30-Resources/attachments/`에 두고, 핵심만 히스토리 노트에 기록.
