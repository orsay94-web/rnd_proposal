# 상담 기초자료 볼트 — Claude 작업 규칙

산학협력단 연구지원 상담 전에 상담 대상의 기초자료와 이력을 빠르게 확인하기 위한 Obsidian 볼트입니다.

## 폴더
- `상담/연구자/` — 교수·연구원 1인당 노트 1개. 파일명: `이름 (소속).md`
- `상담/지원기관/` — 지원기관(예: 한국연구재단) 1곳당 노트 1개. 파일명: `기관명.md`
- `상담/상담기록/` — 상담 1건당 노트 1개. 파일명: `YYYY-MM-DD 대상이름.md`
- `Templates/` — `연구자.md`, `지원기관.md`, `상담기록.md`
- `00-Inbox/` — 정리 전 메모, 받은 자료
- `30-Resources/` — 공고문, 규정, 양식 등 참고자료

## 요청별 동작
- **"○○ 상담 전 기초자료 요약해줘"**
  대상 노트와 링크된 상담기록·지원기관 노트를 모두 읽고 아래 순서로 화면에 요약 (파일 저장 안 함):
  1. 기초정보 (소속, 분야 / 기관이면 주요 사업)
  2. 최근 상담 3건 요점
  3. 진행 중이거나 최근 과제
  4. 미완료 후속 조치
  5. 이번 상담에서 확인하면 좋을 점
- **"방금 상담 내용 기록해줘: …"**
  `Templates/상담기록.md`로 `상담/상담기록/`에 새 노트 생성 → 대상 노트의 '상담 이력'과 '후속 조치'에 링크·항목 추가.
  대상 노트가 없으면 템플릿으로 새로 만든 뒤 진행.
- **"후속 조치 안 끝난 것 보여줘"** → 모든 노트의 `- [ ]` 항목을 대상별로 모아 표시.
- **"○○ 분야 / ○○ 기관 관련 상담 목록"** → frontmatter와 본문을 검색해 표로 표시.
- **"Inbox 정리해줘"** → `00-Inbox/` 자료를 읽어 해당 대상 노트에 반영하고, 원본은 `30-Resources/`로 이동.

## 규칙
- 노트 사이 연결은 `[[위키링크]]`. 연구자 ↔ 지원기관 ↔ 상담기록이 서로 링크되도록 유지.
- 확인되지 않은 정보는 추측해서 쓰지 말고 `(확인 필요)`로 표시.
- 주민등록번호, 계좌번호, 개인 휴대전화 등 민감정보는 기록하지 않음. 입력에 있으면 빼고 알려줄 것.
- 노트를 삭제하지 말고 `40-Archive/`로 이동.
- `.obsidian/` 설정은 수정하지 않음.
